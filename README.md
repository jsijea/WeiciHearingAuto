# WeiciHearingAuto
Android 端自动完成维词听力任务的辅助工具
[![Android](https://img.shields.io/badge/Android-8.0%2B-brightgreen)](https://developer.android.com/)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## 功能
- 自定义错题数量，可指定随机错题数，或手动选择特定题号（支持中英文逗号分隔）。
- 输出每道错题的题干、选项、正确答案及用户选择，并高亮听力原文中对应的关键句
- 时长设置，支持秒、分秒、时分秒三种输入格式（如 `2026`、`26,28`、`1,16,36`）。

## 注意事项
- 如不知道任务id请留空
- 本工具仅供学习交流，请勿用于任何商业或作弊行为。
- 使用前请确保您已获得微词平台的使用授权，并遵守相关服务条款。
- 如遇登录失败或任务异常，请检查网络或账号状态。
